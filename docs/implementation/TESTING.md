# Testing (`backend/tests`)

## Running tests

From **`backend/`** with dev deps:

```bash
pip install -e ".[dev]"
pytest -q
```

CI expectation: **`pytest`** passes. **`tests/api/test_validation_api.py`** is skipped when Postgres is unreachable (local dev); CI should use Compose + migrated DB so these run without skip.

## Docker Compose (same DB as the stack)

The **backend** image bakes **`src/`** at build time and omits **`tests/`**. To exercise **current** tree code from your checkout (without rebuilding the image), mount **`backend/src`** and **`backend/tests`** read-only, install test runners, migrate, then run pytest:

```bash
docker compose run --rm \
  -v "$(pwd)/backend/src:/app/src:ro" \
  -v "$(pwd)/backend/tests:/app/tests:ro" \
  backend sh -c "pip install -q pytest pytest-asyncio && alembic upgrade head && pytest tests/ -q"
```

Do **not** run `pip install -e '.[dev]'` with a read-only `src` mount (editable install needs to write metadata under `src/`).

Requires the **Docker daemon** running. Compose starts **`db`** for this run unless you use **`--no-deps`**.

For more context on services and ports, see [DOCKER.md](DOCKER.md).

## TDD

Prefer **red → green → refactor** for new domain rules. Router tests should stay thin; heavy logic belongs under **`ocean_read/domain/`**.

## Database in tests

Most tests are **pure domain** and need no database.

**`tests/api/test_validation_api.py`** seeds `projects` and `validation_schemas` via sync SQL, then calls the app over **ASGI** (`httpx` + `ASGITransport`). It **skips** if `DATABASE_URL` is unreachable (no local Postgres). For **CI without skips**, run Postgres (e.g. Compose) and apply **Alembic** migrations before `pytest`.

**Wine CSV PDF fixtures** (`tests/fixtures/wine/clean/`, `tests/fixtures/wine/noisy/`, `corpus_index.json`, `schema.json`) are generated by:

```bash
.venv/bin/python tests/fixtures/wine/generate_fixtures.py
```
